This Python program writes one original piece of calming prose to `entry.txt`.

## Run it

```sh
mkdir -p work/output
MAKEFUN_OUTPUT_DIR=work/output python3.13 main.py
```

The contest runner writes to `/output` by default. The program uses only the Python standard library.

The [research branch](https://github.com/auracreation/makefun-quiet-harbor/tree/research) preserves the candidate tournament, raw proxy verdicts, analysis scripts, and validation evidence. The candidate tournament used Codex reviewers. make.fun runs the official GLM-5.3-Flash judge after submission.
